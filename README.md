# Riset-Informatika
Git pengumpulan penugasan mata kuliah Riset Informatika semester 7. Seluruh artikel jurnal, makalah penelitian, dan publikasi terkait yang disitasi atau dirujuk dalam repositori ini tetap menjadi hak kekayaan intelektual penulis dan penerbit masing-masing. Pencantuman materi tersebut semata-mata bertujuan untuk keperluan akademik dan referensi.
